# Orgycaps Saffron Website

A luxury, animated, responsive static website for Orgycaps.

## Files
- `index.html` — website structure and content
- `style.css` — luxury visual design, responsive layout and animations
- `script.js` — scroll reveals and desktop mouse interaction

## GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub Pages will publish the site.
